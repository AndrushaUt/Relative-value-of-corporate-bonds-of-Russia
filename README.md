# Relative Value на рынке корпоративных облигаций РФ

Алгоритмическая стратегия relative value на российских корпоративных облигациях:
ML-модель предсказывает справедливый G-spread, отклонения рыночного спреда от
модельного используются как сигнал недооценки/переоценки.

Курсовая работа, магистратура «Финансовый инжиниринг», НИУ ВШЭ, 2026.

## Исследовательский вопрос

Может ли стратегия на основе ML-предсказания справедливой стоимости давать
доходность сверх пассивных биржевых фондов на корпоративные облигации РФ, если
учесть риск, транзакционные издержки и поправку на множественные сравнения?

Короткий ответ: **на отложенной выборке нет по абсолютной доходности, но да по
профилю риска.** Подробности ниже.

## Данные

| Источник | Что берём |
|---|---|
| MOEX ISS API | дневные цены, доходности, объёмы; кривая бескупонной доходности ОФЗ; индексы; котировки БПИФ |
| Cbonds | кредитные рейтинги, отраслевая принадлежность, финансовые мультипликаторы |
| bo.nalog.gov.ru | отчётность РСБУ эмитентов |
| ЦБ РФ | ключевая ставка, курс USD/RUB |

В выборку вошли 1 793 корпоративные облигации в рублях с фиксированным купоном,
объёмом выпуска от 100 млн руб., без структурных нот и флоатеров.
Фильтр ликвидности: не менее 15 торговых дней в месяц и от 1 млн руб.
среднедневного оборота.

Итоговая панель содержит 295 569 наблюдений «облигация-день» по 967 бумагам
за период с января 2021 по март 2026 (1 308 торговых дней) и 38 признаков.

Фундаментальные показатели подключаются через `merge_asof` с
`direction='backward'` и консервативным лагом 90 дней: на каждую торговую дату
доступна только та отчётность, которая на неё уже была опубликована.

## Модель

Модель предсказывает G-spread, премию доходности облигации над кривой ОФЗ.

В качестве основной модели используется CatBoost, гиперпараметры подобраны
Optuna на первых двух третях фолдов. Валидация walk-forward: 62 фолда,
обучающее окно 12 месяцев, шаг 1 месяц, предсказание на следующий месяц.

Обучаются две версии: без `g_spread_lag1` (чистая справедливая стоимость)
и с лагом (условная справедливая стоимость).

| Модель | MAE, б.п. | R² OOS |
|---|---|---|
| Ridge / OLS | n/a | 0.04 |
| CatBoost без лага | 3.91 | 0.524 |
| CatBoost с лагом | 1.92 | 0.796 |

Разложение SHAP по группам признаков: параметры облигации 57.8 %,
эмитент 20.8 %, макро 17.1 %, взаимодействия 4.2 %.
Состав топ-15 драйверов устойчив до и после структурного разрыва 2022 года
(Spearman 0.915, Jaccard 0.875).

## Дизайн эксперимента

Период с октября 2025 по март 2026 (123 торговых дня) зарезервирован как
отложенная выборка. На нём не обучались модели и не подбирались ни
гиперпараметры, ни пороги стратегии. Все варианты отбирались на основном
периоде, отложенная выборка использована один раз.

### Значимость

Alpha финальной стратегии относительно каждого бенчмарка положительна,
но статистически незначима (`data/nb15_final_alpha.csv`):

| Бенчмарк | α годовых | t | p | β |
|---|---|---|---|---|
| OBLG | +7.6 % | 0.96 | 0.34 | 0.48 |
| SBRB | +11.5 % | 1.42 | 0.16 | 0.22 |
| TBRU | +10.0 % | 1.37 | 0.17 | 0.34 |
| RUCBTRNS | +5.7 % | 0.73 | 0.47 | 0.59 |

Протестировано 28 гипотез (7 вариантов × 4 бенчмарка). После поправки
Бонферрони (α = 0.0018) и FDR **ни один вариант не проходит порог значимости**
(`data/nb16_multiple_testing.csv`).

### Выводы

- По абсолютной прибыли стратегия проигрывает всем трём БПИФ на отложенной
  выборке. Этот период представляет собой растущий рынок при высокой ключевой
  ставке, где выигрывают длинные облигации за счёт переоценки.
- ML-предсказания сами по себе не дают преимущества: naive carry на сыром
  спреде даёт больше прибыли, чем CatBoost без фильтров.
- Основной вклад дают не предсказания, а конструкция портфеля: фильтр
  качества эмитента и взвешивание по силе сигнала.
- Низкая бета (от 0.22 до 0.59) при положительной точечной alpha означает, что
  стратегия имеет смысл как диверсифицирующая надстройка к пассивному
  портфелю, а не как его замена.
- Макро-надстройка на отложенной выборке не активировалась: за 123 дня не было
  ни одного стрессового события, поэтому V11e, V13a и V13b совпадают.

## Структура

```
scripts/
  1_data/        сбор данных из MOEX, Cbonds, РСБУ, ЦБ + сборка панели
  2_model/       обучение CatBoost, baseline-регрессии, кредитный классификатор
  3_strategy/    бэктест-фреймворк, оценка на отложенной выборке, диагностика
notebooks/
  1_pipeline/    основной путь: качество данных, EDA, структурный разрыв,
                 модель, SHAP, сигнал, бэктест, robustness
  2_experiments/ варианты стратегии: фильтры, конструкция, ансамбль,
                 агрегация по эмитенту, макро-надстройка, HRP, множественные
                 сравнения
  figures/       99 графиков
```

Ядро проекта это `scripts/3_strategy/strategy_lib.py`: загрузка сигнала, расчёт
quality/momentum, конструкция портфеля, метрики, блочный бутстрап,
регрессия alpha с HAC-ошибками Newey-West, HRP-аллокатор.

## Запуск

```bash

source .venv/bin/activate
pip install -r requirements.txt
```

Данные в репозиторий не входят, см. раздел ниже. Скрипты ожидают их в `data/`
в корне репозитория.

Полный путь с нуля:

```bash
python scripts/1_data/collect_universe.py
python scripts/1_data/collect_trades.py

python scripts/1_data/build_panel.py
```

`collect_multipliers.py`. Файл с cookies в репозиторий не входит и не должен
в него попадать.

## Ограничения

- Отложенная выборка составляет 123 торговых дня. Для строгих статистических
  выводов этого мало, что и показывает поправка на множественные сравнения.
- Период отложенной выборки не содержит стрессовых событий, поэтому
  макро-надстройка на нём непроверяема.
- Bid-ask spread на истории MOEX недоступен и оценивается статистически через
  Roll estimator, то есть транзакционные издержки приблизительны.
- Фундаментальные данные покрывают 60 % бумаг.
- Результаты получены на одном рынке за один период и не переносятся
  автоматически на другие рынки.
